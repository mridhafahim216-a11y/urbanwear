URBANWEAR CLOTHING STORE
========================

1. Open index.html in Chrome to preview the website.
2. Edit product names/prices in script.js.
3. Replace the WhatsApp number in BOTH index.html and script.js:
   8801000000000
   Example Bangladesh number: 8801XXXXXXXXX
4. To add real product photos, replace the product visual blocks in index.html/script.js
   or ask ChatGPT to customize the site with your photos.
5. This is a front-end starter store. It does not include a real payment gateway,
   database, inventory dashboard, or secure server-side order system.

FREE HOSTING OPTIONS
--------------------
GitHub Pages:
- Create a GitHub account.
- Create a new PUBLIC repository.
- Upload index.html, style.css, script.js.
- Repository > Settings > Pages > Deploy from branch > main > /(root) > Save.
- Wait for deployment, then open the Pages URL.

Netlify:
- Create a Netlify account.
- Add/import the site or use Netlify Drop.
- Upload the website folder.
- Netlify gives you a free .netlify.app address.

GOOGLE SEARCH
-------------
Chrome does not host websites. After hosting, you can submit the live site
to Google Search Console for indexing. A custom .com domain is optional.
